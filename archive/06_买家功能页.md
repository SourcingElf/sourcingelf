# Claude Design使用提示

- 采购任务页：进行中/已完成的分区很重要——进行中任务应感觉充满活力（深蓝左边框），已完成应感觉已归档（灰色，折叠）。
- 创建任务页：明细卡片部分是最复杂的部分。每张明细卡片应感觉自成一体。"+ Add Item"按钮应轻松自然——虚线边框效果好。
- 申请卡片：紫色"Applied"和绿色"Connected"左边框是关键视觉信号，与00_设计规范.md中的状态徽章系统保持一致。
- 精选供应商页：顶部筛选栏，然后是干净的视频卡片垂直列表。播放按钮必须是每张卡片的主要交互元素。
- 请求气泡弹出流程：Watch（观看）→ Request（申请）→ 弹出框 → Send → "Sent ✓"。三步流程，零页面跳转，快速无摩擦。
- 已连接供应商：随着每次成功连接不断增长。让它感觉像专业通讯录，而非数据表格。
