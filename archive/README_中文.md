# SourcingElf — 中文设计使用指南

## 如何使用这套文件

本文件夹包含SourcingElf平台的完整设计规范，适用于在Claude Design中设计每个页面。

**工作流程：**
1. 始终先加载 `00_设计规范.md`——它定义了全局通用的颜色、字体、组件和规则。
2. 再加载您要设计的页面对应的规范文件。
3. 生成设计时同时参考两个文件。

## 核心设计原则（摘要）

1. **两个端口，两种主色**：供应商端 = 深蓝 `#1a2744`，买家端 = 红色 `#b91c1c`
2. **字体**：Playfair Display用于所有标题，DM Sans用于所有UI和正文
3. **调性**：高端、国际化、专业——而非普通SaaS产品
4. **图片**：编辑类时装摄影（Unsplash），绝不使用产品目录式素材
5. **动效**：页面加载时卡片依次淡入上移，悬停时卡片轻微上移，无装饰性动画
6. **Elfa**：在双端全程使用星球轨道图标的深蓝圆形头像代表Elfa

## 业务逻辑提醒（交互设计参考）

- 买家身份**隐藏**直到供应商确认对接（显示遮码名称，如"A** Fashion Ltd"）
- 供应商每次对接扣减**1个credit**（US$138），在确认时扣除
- 采购任务申请：提交申请时**预留**credit，对接确认后**正式扣减**，任务到期无对接则**退还**
- 所有买家必须经Elfa**验证**后才能与供应商对接
- Lead Form买家：邮箱、手机、WhatsApp三项均为**必填**
- 同一供应商对同一采购任务只能申请**一次**
- 同一买家可与一个任务的**多个**供应商对接（不限数量）
- IM聊天：V1仅支持文字和图片。聊天记录**永久保存**。
