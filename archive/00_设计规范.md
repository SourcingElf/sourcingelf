# SourcingElf — 全局设计规范

## 品牌概述
SourcingElf 是一个专业B2B服装采购撮合平台，连接经过审核的服装供应商与全球买家。视觉风格应体现权威感、国际化与专业信赖——接近《金融时报》或 Monocle 的审美，而非典型的SaaS产品风格。高端、沉稳、精准。

---

- 仅图标：星球轨道标志（用于favicon、App图标、小空间）

### 色彩使用原则
- 禁止在白色背景上使用紫色渐变（典型AI审美，需避免）
- 深蓝背景必须配白色或浅色文字
- 红色作为点缀色，谨慎使用——除数据条外不大面积铺红色背景
- 所有交互元素必须有清晰的悬停和聚焦状态

## 字体规范

### 字体家族
- **展示/标题字体**：Playfair Display（衬线体）— 字重 400、600、700
- **正文/UI字体**：DM Sans — 字重 300、400、500、600
- Google Fonts CDN：`https://fonts.googleapis.com/css2?family=Playfair+Display:ital,wght@0,400;0,600;0,700;1,400&family=DM+Sans:wght@300;400;500;600&display=swap`

### 字号层级
| 层级 | 字体 | 字号 | 字重 | 行高 |
|------|------|------|------|------|
| Hero标题 | Playfair Display | 52–60px | 700 | 1.1 |
| 页面标题 | Playfair Display | 38–44px | 700 | 1.15 |
| 区块标题 | Playfair Display | 28–34px | 600 | 1.2 |
| 卡片标题 | DM Sans | 18px | 600 | 1.3 |
| 正文大号 | DM Sans | 16px | 400 | 1.8 |
| 正文 | DM Sans | 14px | 400 | 1.7 |
| 标签/说明 | DM Sans | 11–12px | 500–600 | 1.4 |
| 眉题 Eyebrow | DM Sans | 11px | 600 | 1 |

### 字体使用原则
- 眉题标签：全大写，字间距 0.15em，颜色统一用红色 `#b91c1c`
- 区块标题：句首大写，禁止全大写
- 深色背景上的正文：`rgba(255,255,255,0.65)`——不使用纯白色长段落
- Playfair Display 斜体仅用于Hero标题中的强调词

## 阴影规范
极简阴影原则——通过边框和背景对比传递层次，而非厚重阴影。

| 层级 | CSS |
|------|-----|
| 平面 | `border: 1px solid rgba(26,39,68,0.10)` |
| 卡片悬停 | `box-shadow: 0 12px 40px rgba(26,39,68,0.10)` |

## 图标规范
- 风格：描边线条，1.5–2px描边，圆形端点
- 尺寸：20px（标准），16px（行内），24px（特色）
- 来源：Heroicons 或 Lucide（风格一致）
- 同一场景不混用描边与填充图标
- 颜色：继承文字色，或使用语义色

---

## 动效规范

### 原则
- 仅用于有意义的交互——不使用装饰性动画
- 时长：150ms（微交互），250ms（标准），400ms（页面过渡）
- 缓动：大多数用 `ease`，滑入用 `cubic-bezier(0.16,1,0.3,1)`
- 页面加载：Hero元素依次从下淡入（每项延迟100ms）

### 标准过渡
```css
/* 默认交互 */
transition: all 200ms ease;

/* 卡片悬停 */
transition: transform 200ms ease, box-shadow 200ms ease;

/* 页面加载淡入 */
@keyframes fadeUp {
  from { opacity: 0; transform: translateY(16px); }
  to   { opacity: 1; transform: translateY(0); }
}
```

## 文案风格
- 语言：英文为主（V1）
- 语气：专业、直接、自信——不使用企业套话
- 标题：句首大写
- 按钮文字：动词开头（"Connect"、"Apply"、"Create Task"、"Request"）
- 错误提示：具体且有指引（"You need at least 1 credit to connect. Top up now →"）
- 空状态：鼓励性文字（"No buying leads yet — Elfa will notify you when new tasks arrive"）
- 确认弹窗：清楚说明后果（"This will deduct 1 credit (US$138) from your balance"）
