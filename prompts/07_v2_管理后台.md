## 供应商管理页

筛选栏：搜索 + 状态/国家下拉 + [Filter]

表格列：公司（名称+国家）/ 联系人 / 对接数 / 申请数 / 注册日期 / 状态徽章 / [View]

**供应商详情（两列65%/35%）：**

左：资料卡，标签页 Profile / Products / Production / Certifications
管理员备注文本区域（内部可见）+ [Save Notes]

右：
统计卡：总对接数 / 待处理申请 / 本月支付金额
操作卡：
- [View Chat History]
- [Suspend Account]红色描边
- [Activate Account]（停用时显示）

---

## 买家管理页

表格：公司 / 联系人 / 买家类型 / 验证状态 / 对接数 / 任务数 / 注册日期 / [View]

**"Pending Verification"标签页**（优先处理，红色数字徽章）

**买家详情：**
两列布局。

右侧操作：
- [Mark as Verified] **绿色主要按钮——页面最突出**
  → 确认："此操作将允许该买家与供应商对接。"
- [Request More Info] → WhatsApp消息模板
- [View Chat History]
- [Suspend]

验证时间线（Profile标签内底部）：
```
24 Apr  Lead form submitted
25 Apr  Elfa: WhatsApp contact attempted
26 Apr  Elfa: Background check completed
26 Apr  Admin marked as Verified ✓
```
