# SourcingElf MVP v2 — 数据库变更说明

## 与v1的对比

### 删除的表（视频功能移至第二阶段）
- `videos` — 推广视频
- `video_materials` — 视频素材
- `video_selling_points` — 视频卖点

### 删除的字段
- `buyer_requests` 表 — 删除（MVP不再有Featured Suppliers发出的请求）
- `credits` 表 — 删除（改为每次直接支付，无余额体系）
- `credit_transactions` 表 — 删除

### 修改的表

**`payments` 表（扩展）：**
原来只记录充值，现在记录每笔对接支付。

```sql
CREATE TABLE payments (
    id                  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    supplier_id         UUID NOT NULL REFERENCES supplier_profiles(id),
    buyer_id            UUID NOT NULL REFERENCES buyer_profiles(id),
    connection_id       UUID REFERENCES connections(id),
    lead_application_id UUID REFERENCES lead_applications(id),

    -- Stripe信息
    stripe_payment_intent_id  TEXT UNIQUE,
    stripe_payment_link_id    TEXT,

    -- 金额
    amount_usd          NUMERIC(10,2) NOT NULL,
    is_promo_price      BOOLEAN DEFAULT false,   -- 是否促销价

    -- 状态
    status              TEXT NOT NULL DEFAULT 'pending'
                        CHECK (status IN ('pending', 'succeeded', 'failed', 'refunded')),

    paid_at             TIMESTAMPTZ,
    created_at          TIMESTAMPTZ DEFAULT now()
);
```

**`lead_applications` 表（简化）：**
删除credit相关字段，改为payment关联。

```sql
-- 删除字段：
-- credit_transaction_id
-- credit_status

-- 新增字段：
payment_id      UUID REFERENCES payments(id),   -- 关联支付记录
payment_status  TEXT DEFAULT 'unpaid'
                CHECK (payment_status IN ('unpaid', 'paid', 'refunded'))
```

**`connections` 表（简化）：**
```sql
-- 删除字段：
-- credit_transaction_id

-- 新增字段：
payment_id      UUID REFERENCES payments(id),   -- 关联支付记录
unlocked_at     TIMESTAMPTZ                     -- 支付完成，IM解锁时间
```

### 新增的表

**`pricing_config` 表（定价配置）：**
```sql
CREATE TABLE pricing_config (
    id                  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    standard_fee        NUMERIC(10,2) NOT NULL DEFAULT 138.00,
    promo_fee           NUMERIC(10,2),           -- 促销价，可空
    promo_active        BOOLEAN DEFAULT false,    -- 是否启用促销
    promo_expires_at    TIMESTAMPTZ,              -- 促销到期时间，可空
    promo_description   TEXT,                     -- 促销说明，如"Early bird: first 100 suppliers"
    updated_at          TIMESTAMPTZ DEFAULT now(),
    updated_by          UUID REFERENCES users(id)
);

-- 初始数据
INSERT INTO pricing_config (standard_fee, promo_fee, promo_active, promo_description)
VALUES (138.00, 99.00, false, 'Early registration offer for first 100 suppliers');
```

## 核心业务逻辑变更

### 支付流程（新）
```
买家发出对接邀请
    → lead_applications.status = 'buyer_accepted'
    → 通知供应商："买家已接受，请支付对接费用"

供应商点击"Pay & Connect"
    → 创建 payments 记录（status: pending）
    → 调用Stripe Payment Intent
    → 等待Stripe Webhook回调

Stripe支付成功（Webhook）
    → payments.status = 'succeeded'
    → connections 记录创建
    → lead_applications.payment_status = 'paid'
    → connections.unlocked_at = now()
    → IM聊天解锁
    → 通知双方
```

### 定价逻辑
```
每次支付时查询 pricing_config：
- 如果 promo_active = true 且 promo_expires_at > now()
    → 使用 promo_fee（US$99）
    → payments.is_promo_price = true
- 否则
    → 使用 standard_fee（US$138）
```

### 删除的逻辑
- ~~Credit预扣/退还逻辑~~ — 删除
- ~~视频审核流程~~ — 删除
- ~~充值套餐~~ — 删除
- ~~Featured Suppliers / buyer_requests~~ — 删除

## Supabase执行步骤

在Supabase SQL Editor执行以下操作：

### 第一步：删除不需要的表
```sql
DROP TABLE IF EXISTS video_selling_points CASCADE;
DROP TABLE IF EXISTS video_materials CASCADE;
DROP TABLE IF EXISTS videos CASCADE;
DROP TABLE IF EXISTS buyer_requests CASCADE;
DROP TABLE IF EXISTS credit_transactions CASCADE;
DROP TABLE IF EXISTS credits CASCADE;
```

### 第二步：修改 lead_applications 表
```sql
ALTER TABLE lead_applications
    DROP COLUMN IF EXISTS credit_transaction_id,
    DROP COLUMN IF EXISTS credit_status,
    ADD COLUMN payment_id UUID REFERENCES payments(id),
    ADD COLUMN payment_status TEXT DEFAULT 'unpaid'
        CHECK (payment_status IN ('unpaid', 'paid', 'refunded'));
```

### 第三步：修改 connections 表
```sql
ALTER TABLE connections
    DROP COLUMN IF EXISTS credit_transaction_id,
    ADD COLUMN payment_id UUID REFERENCES payments(id),
    ADD COLUMN unlocked_at TIMESTAMPTZ;
```

### 第四步：修改 payments 表
```sql

                                CHECK (status IN ('pending', 'succeeded', 'failed', 'refunded')),
    paid_at                     TIMESTAMPTZ,

);
```
